# Study on the Helpfulness of Explainable Artificial Intelligence

This repository provides the implementation for the research paper:  
**"Study on the Helpfulness of Explainable Artificial Intelligence"**  
by Tobias Labarta, Elizaveta Kulicheva, Ronja Froelian, Christian Geißler, Xenia Melman, and Julian von Klitzing.  

**Paper URL**: [arXiv:2410.11896v1](https://arxiv.org/pdf/2410.11896v1)

---

## Overview

Explainable Artificial Intelligence (XAI) is pivotal for the successful deployment of machine learning systems, particularly in high-stakes applications such as medical diagnostics and autonomous driving. While a variety of XAI methods exist, selecting the most appropriate one for a specific use case remains challenging due to the lack of standardized evaluation methods that incorporate human factors.

This research introduces a novel evaluation framework that measures the effectiveness of XAI methods based on human decision-making performance. The key idea is to evaluate XAI methods through a **"proxy task"**, where human participants' ability to make correct decisions using the explanations provided by the AI serves as a measure of the explanation's helpfulness. This approach emphasizes the role of trust, skepticism, and interpretability in assessing XAI methods.

---

## Key Contributions

1. **Human-Centric XAI Evaluation**:  
   A new framework is proposed to evaluate XAI methods by measuring their impact on human performance in tasks that simulate real-world decision-making.

2. **User Study**:  
   A user study was conducted to compare state-of-the-art XAI methods, analyzing their effectiveness in:
   - Fostering trust and skepticism.
   - Enabling users to correctly evaluate the AI's decisions.

3. **Recommendations for Future Work**:  
   The study highlights the need for more objective, task-based, human-centered evaluations of XAI methods and encourages researchers to adopt and extend this approach.

## Core Concepts

### 1. Proxy Task
The proxy task is a simplified, controlled experiment designed to mimic a real-world decision-making scenario. Participants use the explanations generated by an XAI method to make decisions. The quality of the explanations is inferred from the participants' task performance.

### 2. XAI Methods
This implementation supports multiple state-of-the-art XAI methods, including:
- **SHAP** (SHapley Additive exPlanations)
- **LIME** (Local Interpretable Model-agnostic Explanations)
- **Grad-CAM** (Gradient-weighted Class Activation Mapping)

Each method generates explanations for AI model predictions, which are then presented to the user during the proxy task.

### 3. Evaluation Metrics
The following metrics are used to evaluate the helpfulness of XAI methods:
- **Trust**: The extent to which users rely on the AI's predictions.
- **Skepticism**: The ability of users to question incorrect AI predictions.
- **Decision Accuracy**: The percentage of correct decisions made by users during the proxy task.

## Usage

### 1. Data Preparation
Prepare the dataset for the proxy task by placing it in the `data/` directory. Preprocess the data using the utilities provided in `utils/preprocessing.py`.

```bash
python utils/preprocessing.py --input data/sample_dataset.csv --output data/processed_data/
```

### 2. Train the AI Model
Train the AI model using the script in the `models/` directory:

```bash
python models/model.py --data data/processed_data/
```

### 3. Generate Explanations
Run the `explainers.py` script to generate explanations using different XAI methods:

```bash
python models/explainers.py --model models/trained_model.pth --data data/processed_data/
```

### 4. Proxy Task Evaluation
Evaluate the helpfulness of the explanations through the proxy task:

```bash
python experiments/proxy_task.py --explanations explanations/ --data data/processed_data/
```

This script will compute and save the evaluation metrics.

### 5. User Study Simulation
Simulate the user study environment for testing and evaluation:

```bash
python experiments/user_study_simulation.py --explanations explanations/ --metrics output/metrics.csv
```

## Results and Insights

The user study conducted using this framework revealed significant differences in the performance of state-of-the-art XAI methods. Key findings include:
- Some methods were more effective in building user trust, while others encouraged skepticism.
- The ability to evaluate the correctness of AI decisions varied considerably across methods.

These findings underscore the importance of task-based, human-centric evaluations in selecting appropriate XAI methods for specific applications.

## Future Work

The following directions are suggested for future research:
- Extending the proxy task framework to more complex and diverse real-world scenarios.
- Investigating the impact of user expertise and cognitive biases on the effectiveness of XAI methods.
- Developing standardized benchmarks for XAI evaluation.
